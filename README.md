# Praktikum 5 — JavaScript Dasar dan Manipulasi HTML

## 1. Tujuan Praktikum
1. Memahami dasar penggunaan JavaScript.
2. Mempraktikkan variabel, fungsi, operasi aritmetika, dan percabangan.
3. Memahami penggunaan event untuk merespons tindakan pengguna.
4. Memanipulasi elemen HTML menggunakan JavaScript.
5. Membuat kalkulator nilai mahasiswa.

## 2. Daftar Latihan
- Latihan 1: Menampilkan Hello World.
- Latihan 2: Menggunakan alert dan prompt.
- Latihan 3: Melakukan operasi aritmetika.
- Latihan 4: Memeriksa kelulusan menggunakan if-else.
- Latihan 5: Menggunakan switch-case.
- Latihan 6: Memeriksa bilangan genap atau ganjil.

- Latihan 8: Menghitung total menu makanan.

- Eksperimen Mandiri: Tabel perkalian, pemeriksaan bilangan, validasi form, menu tambahan, dan manipulasi tampilan.

## 3. Jawaban Pertanyaan Praktikum

### 1. Apa perbedaan var, let, dan const?
`var` digunakan untuk mendeklarasikan variabel dengan cakupan fungsi. `let` digunakan untuk variabel yang nilainya dapat diubah. `const` digunakan untuk variabel yang tidak dapat diberi nilai baru setelah deklarasi.

### 2. Apa fungsi addEventListener()?
`addEventListener()` digunakan untuk menjalankan suatu fungsi ketika peristiwa tertentu terjadi, misalnya ketika tombol diklik.

### 3. Apa perbedaan == dan ===?
`==` membandingkan nilai dengan kemungkinan konversi tipe data, sedangkan `===` membandingkan nilai sekaligus tipe datanya.

### 4. Apa fungsi document.getElementById()?
Perintah ini digunakan untuk mengambil elemen HTML berdasarkan nilai atribut id-nya.

### 5. Apa fungsi prompt() dan alert()?
`prompt()` digunakan untuk meminta masukan dari pengguna, sedangkan `alert()` digunakan untuk menampilkan pesan dalam kotak dialog.

### 6. Apa fungsi if-else dan switch-case?
`if-else` digunakan untuk menjalankan perintah berdasarkan kondisi. `switch-case` digunakan untuk memilih perintah berdasarkan nilai yang cocok dengan salah satu kasus.

### 7. Apa manfaat manipulasi DOM?
Manipulasi DOM memungkinkan JavaScript mengubah teks, warna, tampilan, dan isi elemen HTML secara dinamis tanpa harus membuat halaman baru.
